# Kod-Asistan
Proje Yazarı : Akın Güler
# Projenin Adı : Kod-Asistan v0.1
## Projenin amacı : Kullanıcılara günlük işlerinde (hesaplama, selamlama vb.) yardımcı
olacak bir dijital asistan tasarlamak
## Projenin Hedefleri: bu asistanın ilerleyen zamanlara hangi özellikleri kazanıcanı
* selamlama v1.0
* Kolay veri girişli dört işlem yapan hesaplama uygulaması v1.1
* hesaplamaların sonuçlarını ondalıklı gösterebilme v2.0
* hatalı veri girişini engelleme v2.1
## projenin kapsamı:
* girilen iki sayı toplama, çıkarma, çarpma ve bölme işlemi yapabilmek
    * BAŞLA
    * "1.sayı:" gir,a
    * "2.sayı:" gir,b
    * toplam-a+b
    * fark=a-b
    * carpim=a*b
    * bolum=a/b
    * Yaz "a+b-",toplam
    * yaz "a-b",fark
    * yaz "a*b",carpim
    * yaz "a/b",bolum
    * BİTTİ
